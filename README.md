# Mobile Interview Assignment

It is a small messenger SDK (for Android and iOS platforms) setting the stage 
for the mobile engineer test assignment.

## Start here

Start with [`docs/ASSIGNMENT.md`](docs/ASSIGNMENT.md). It explains the task, what
to build, what to hand in, and how to test your work.

## What's here

- `docs/ASSIGNMENT.md`: the assignment instructions. **Start here.**
- `protocol/PROTOCOL.md`: the WebSocket message format the SDK uses.
- `protocol/mock-server/`: an optional local server for manual testing.
- `android/`: the Android (Kotlin) starter kit.
- `ios/`: the iOS (Swift) starter kit.

## Submitting your solution

When you are ready for us to look at your solution, do the following in **your
repo**:

1. Create a Pull Request targeting the `main` branch. The solution must be
   implemented in a separate branch.
2. Add us as external contributors to your private repo, so we can review your
   Pull Request.

When we are done, you of course own the code you made.
